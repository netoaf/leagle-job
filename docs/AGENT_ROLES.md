# Agent roles

Which tool does what in this repository. Keep this file short and update it when the split changes.

- Code changes and tests: Claude Code (reads `AGENTS.md` / `CLAUDE.md` first).
- Pull request review: GitHub Copilot automatic review, with Claude `/code-review` as the fallback.
- Second opinion and research: ChatGPT, outside the repository; its output is advice, not a change.

Never commit secrets, CVs or personal data. Merge and release stay with the repository owner.
